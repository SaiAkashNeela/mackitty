Privacy Policy

Effective Date: September 2026 · macOS Native Standard

🔒 Zero Data Collection Principle: MacKitty runs 100% locally on your Mac. We do not operate remote servers, tracking pixels, analytics daemons, or user identifiers. Your data never leaves your computer.

1. Overview & Commitment

MacKitty ("the App") is developed as a respectful, private system utility for macOS. We believe disk maintenance tools have zero legitimate reason to collect personal data, examine personal documents, or transmit telemetry back to remote endpoints.

2. Data We Do Not Collect

MacKitty does not collect, store, transmit, or sell:

  • Personal identification information (names, emails, IP addresses).
  • Hardware identifiers (UDIDs, serial numbers, MAC addresses).
  • Usage statistics, analytics, crash logs, or telemetry.
  • Contents of any user files, documents, photos, or browsing activity.

3. Local Filesystem Access

MacKitty requests local macOS filesystem permissions solely to measure directory sizes and delete user-authorized cache files. Specifically:

  • Developer caches: ~/Library/Developer/Xcode/DerivedData and compiler module caches.
  • Package archives: ~/Library/Caches/Homebrew and npm/yarn tarballs.
  • Application temporary logs: Diagnostic crash reports and ephemeral cache directories.

Personal boundaries: MacKitty never reads, parses, or modifies files inside ~/Documents, ~/Desktop, ~/Pictures, iCloud containers, Keychain stores, or Git repositories.

4. Third-Party Services & Network Activity

MacKitty includes zero third-party advertising SDKs, zero analytics libraries, and makes no network requests during scan or cleanup operations. The website is hosted statically with zero trackers or invasive tracking cookies.

5. macOS Security & Permissions

MacKitty works within the macOS security model. All disk access respects macOS Transparency, Consent, and Control (TCC) user prompts.

6. Contact

If you have questions regarding this privacy policy, you can reach out via GitHub or through the developer profile at saiakashneela.com.
